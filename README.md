# Corporate Bankruptcy Prediction: Handling Imbalanced Financial Data

## 💻 Project Overview
This project tackles a critical real-world financial problem: predicting corporate bankruptcy. Since bankruptcies are rare events compared to healthy companies, this is a classic **Imbalanced Data Classification** problem. 

The project focuses not just on standard technical metrics, but on **business-driven evaluation**, aiming to minimize the financial risk of missed bankruptcies while maintaining a healthy threshold for identifying viable companies.

## 📊 Objective & Data
* **Goal:** Classify companies as 'Healthy' or 'Bankrupt' based on their financial indicators.
* **Challenge:** Dealing with highly skewed/imbalanced classes (very few bankruptcies vs. many healthy companies).
* **Outputs:** An automated pipeline that evaluates models and exports a detailed, metric-rich Excel report (`Final_Data_For_Excel.xlsx`) for stakeholders.

## 📂 Repository Structure
* `corporate_bankruptcy_analysis.ipynb`: A detailed Jupyter Notebook containing Exploratory Data Analysis (EDA), data visualization, and step-by-step model evaluation. **Best for viewing results and insights.**
* `bankruptcy_model.py`: A clean, modular Python script containing the core machine learning pipeline. **Best for integration and production use.**
* `Final_Data_For_Excel.xlsx`: The automated report generated by the script, including all business metrics.

## ⚙️ Evaluation Strategy (Business Logic)
Standard "Accuracy" is a misleading metric in imbalanced datasets. Therefore, the models in this pipeline were evaluated using a custom, cost-sensitive approach focusing on:
1. **Miss Rate (False Negative Rate):** The primary focus was calculating and minimizing the number of actual bankruptcies missed by the model. In a real-world scenario, this is the most costly error for an investor or bank.
2. **Specificity (True Negative Rate):** Ensuring a strict baseline criterion of correctly identifying at least 70% of the healthy companies, so the model doesn't blindly reject every company to be "safe."
3. **Core ML Metrics:** Confusion Matrix (TP, TN, FP, FN), Precision, Recall (Sensitivity), and F1-Score.
